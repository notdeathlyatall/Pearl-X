# Pearl X 1.0.0

First release. Pearl X is a lightweight, entirely client-side Minecraft Fabric mod with two
completely independent features: a pearl location tracker and a universal pearl travel animation.
Nothing is uploaded, no server-side installation is required, and the two features share no timer
and no enable switch.

## Downloads

Pick the single jar that matches your exact Minecraft version and put it in `mods`. The version is in
the file name: `pearlx-<minecraft>-1.0.0+mc<minecraft>.jar`.

| Minecraft | Jar |

`SHA256SUMS.txt` lists the checksum of every jar in this release.

## Requirements

* Fabric Loader 0.16.0 or newer
* [Fabric API](https://modrinth.com/mod/fabric-api) - required
* [Mod Menu](https://modrinth.com/mod/modmenu) - optional, needed to open the settings screen
* Java 21 for the 1.21.x jars, Java 25 for the 26.x jars

## Feature One: Pearl Location Tracker

* Detects Ender Pearls thrown by the local player only; other players' pearls are ignored.
* Tracks several pearls at once, each with its own record and position.
* Saves locations as compact JSON under `config/pearlx/worlds/`, one small file per server or
  single-player world, keyed by the server address or the level name.
* Cleans records up when a pearl lands or is retrieved, and keeps records when a pearl is only out of
  view in an unloaded chunk.
* Writes only on real changes, on a background thread.
* Has its own saving interval (value + seconds/minutes/hours) that controls nothing else.

## Feature Two: Universal Pearl Travel Animation

* Watches for your thrown pearls independently of the tracker.
* Waits for its own configurable trigger delay, then plays a pearl-themed animation: expanding portal
  ring, end rod sparks, electric sparks, dragon breath and a closing burst, with synced start and
  finish sounds and a configurable volume.
* Visual effects and sound toggle separately; 0% volume is silent.
* One animation per pearl, cancelled when that pearl lands, is retrieved, or the world changes, and
  never replayed after a restart or server switch.

## Settings

Full tabbed screen (General, Tracker, Animation, Storage, Advanced) reachable from Mod Menu, with
tooltips on every control and confirmation dialogs for every destructive storage action. Settings
live in `config/pearlx/pearlx.json` and are validated on load.

## Storage actions

Reset the current server, reset the current single-player world, reset all servers, reset all worlds,
or clear everything - each behind a confirmation dialog.

* `./gradlew :tests:test` passes all 41 tests, including the seven independence rules.

## Known limitations

* **No in-game run.** This release was built in a headless environment. Particle rendering, the
  settings screen layout, Mod Menu integration and live pearl detection are compiled for every
  version but were never executed inside Minecraft.
* **OneConfig is not linked.** Its per-version Kotlin config API would become a hard dependency.
  Pearl X opens from Mod Menu, which OneConfig also lists.
* Client-side only: no server component, no telemetry, no network access.
